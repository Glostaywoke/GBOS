About

A browser-based patcher for the GBOS firmware used on the EverDrive GB Rev.H Pro+ flash cartridge.

Lets you rename UI strings and change the CGB/DMG color palette. No install, no server — just open the .html file.

Original GBOS by:
I. Golubovskiy
(krikzz)

This tool is unofficial and unaffiliated with Krikzz.

Instructions

1. Click Browse or drop your GBOS.GB file onto the upload area.

2. Edit strings and colors using the tabs.

3. Click Build patched ROM.

4. Right-click the download link → Save link as...

5. Flash using the EverDrive OS update procedure.

Notes

All edits are non-destructive — original bytes are preserved in memory until you build.

Header checksum is auto-repaired on every build.

The caution label marks strings that affect cart flashing behavior.

Character counters turn orange / red near the byte limit.

CGB Color Palette — Game Boy Color Mode

BG palette 0, the only palette used for all GBOS menu rendering on CGB/GBC hardware. Four colors: background fill, text, selected row highlight, and border/inactive elements.
