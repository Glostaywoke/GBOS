How To Use

1. Drop GBOS.GB onto the upload area.

2. Edit using the tabs. Modified fields turn yellow.

3. Click Review & Build to see a summary of all changes.

4. Download the patched ROM or a small .ips patch file.

5. Flash via the EverDrive OS update procedure.

Ctrl+B to build instantly.
